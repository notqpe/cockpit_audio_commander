# 🏁 Cockpit Commander

Управление звуком и медиа с геймпада для симрейсинга. Прикрути геймпад PS3 к кокпиту
и рули громкостью отдельных приложений, ставь треки на паузу и переключай их — не отпуская руль.

Работает с геймпадом PS3 и любым устройством DirectInput/XInput. **Управление звуком — только Windows.**

---

## Быстрый старт (из исходников)

1. Установи [Python 3.10+](https://www.python.org/downloads/) (при установке отметь галочку *Add Python to PATH*).
2. В папке проекта открой командную строку и выполни:
   ```
   pip install -r requirements.txt
   python cockpit_commander.py
   ```

## Собрать один .exe (чтобы отправить друзьям)

Двойной клик по **`build_exe.bat`** — после сборки готовый файл появится в `dist\CockpitCommander.exe`.
Его можно отправлять как есть, Python на чужом ПК не нужен.

---

## Драйвер для геймпада PS3

Windows не всегда видит DualShock 3 «из коробки». Если геймпад не определяется, поставь один из драйверов:
- **DsHidMini** (современный, рекомендуется), либо
- **ScpToolkit** (старый, но рабочий).

После установки геймпад появится как обычный контроллер, и в шапке приложения загорится зелёный индикатор.

## Как пользоваться

**Назначения** — вкладка с командами.
- Нажми **НАЗНАЧИТЬ**, затем нужную кнопку на геймпаде — она привяжется к действию.
- Выбери действие из списка. Для команд по конкретному приложению впиши имя процесса
  (например `spotify`, `chrome`, `TeamSpeak3` — имя `.exe` без расширения, как в диспетчере задач).
- Кнопкой **+ Добавить** создавай сколько угодно назначений. Поддерживаются кнопки и крестовина (D-Pad).

**Микшер** — живой список приложений, которые сейчас играют звук. Тяни ползунок — громкость меняется сразу.

**Настройки** — шаг громкости, акцентный цвет интерфейса и название в заголовке.

Все настройки сохраняются автоматически в
`%APPDATA%\CockpitCommander\config.json`.

---

## Доступные действия

| Действие                | Что делает                                    |
|-------------------------|-----------------------------------------------|
| Play / Pause            | Пауза/воспроизведение (медиа-клавиша)         |
| Следующий / Предыдущий  | Переключение треков                           |
| Стоп                    | Остановка воспроизведения                     |
| Общая громкость + / −   | Системная громкость                           |
| Общий mute              | Выключить/включить весь звук                   |
| Громкость приложения + / − | Громкость одного приложения                |
| Mute приложения         | Заглушить одно приложение                      |

---

## Автозапуск с Windows (по желанию)

Нажми `Win + R`, введи `shell:startup`, и положи в открывшуюся папку ярлык на `CockpitCommander.exe`.
Теперь приложение стартует вместе с системой.
